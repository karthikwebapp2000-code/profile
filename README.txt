SENDHUR PANDIAN ULAGAM — WEBSITE PROTOTYPE

Quick start:
1. Extract this ZIP file.
2. Open index.html in a modern browser.
3. Tamil welcome scene plays first (0–5 seconds).
4. English Welcome + 🤝 scene plays next (5–10 seconds).
5. The Tamil welcome scene returns automatically (10–15 seconds).
6. The circular reveal opens the main website after 15 seconds.
7. Use “Skip intro” to go straight to the website, or “↻ Replay” to replay the intro.
8. Use the language selector to switch the landing page between Tamil and English.
9. “Begin your journey” and “Log in” open front-end demo forms.

Notes:
- Front-end prototype only. Authentication, database, email, and account creation are not connected.
- The Tamil scene includes the folded-hands 🙏 overlay; the English scene uses 🤝.
- Google Fonts are loaded from the internet; system fallback fonts are included.
- For a public website, upload index.html to your web host and configure the domain/HTTPS.
